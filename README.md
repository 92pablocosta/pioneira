# Pioneira — Lavanderia de Autosserviço

Landing page institucional da **Pioneira**, primeira lavanderia de autosserviço de Sousa-PB.

**Live:** [pioneira no GitHub Pages](https://92pablocosta.github.io/pioneira-lavanderia/) <!-- update URL after deploy -->

---

## Stack

Zero build. Single file.

- HTML5 + CSS3 + JS vanilla (`index.html`)
- Google Fonts via CDN (Bricolage Grotesque + Plus Jakarta Sans)
- Google Maps via iframe embed
- Sem npm, sem bundler, sem framework

## Estrutura

```
index.html        — toda a página (HTML + CSS embutido + JS)
info/             — contexto operacional do negócio (gitignored)
CLAUDE.md         — instruções para o Claude Code
```

## Deploy

**GitHub Pages:** Settings → Pages → Source: `main` / root

**Netlify drag-and-drop:** arrastar a pasta para [app.netlify.com/drop](https://app.netlify.com/drop)
